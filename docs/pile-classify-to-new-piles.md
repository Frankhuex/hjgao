# 牌堆分类到新牌堆

牌堆查看器底栏提供“分类到新牌堆”。待取区为空时按钮隐藏；有牌时可提交。待取区中的牌按卡组 `ordered_card_templates` 建立的类型顺序分组，组内保持类型子序列顺序，同一张牌的副本按 ID 顺序排列。空类型显示为“未分类”，其他类型直接作为新牌堆的初始显示名。

提交链路沿用牌堆查看占用：`DeckViewerUI` 收集两列 ID 并设置 pending，`PileAccessor.request_classify_to_new_piles` 转发到服务器，服务器校验真实发送者、`PILE_VIEW` owner、全局锁、ID 分区完整性和待取区非空。服务器先准备全部 detached Pile，再一次性改写源栈、加入新堆、广播源栈，最后释放源堆占用。准备或校验失败不会修改任何牌堆；成功后源堆保留，即使为空也保留，查看器随占用释放关闭。

新堆从源堆旁边开始沿世界 X 轴向外连续排列，间距复用类型牌堆布局常量，继承源堆的水平朝向，位置使用桌面高度。服务器分组顺序决定网络节点和空间顺序，允许超出桌面边界及与其他物体重叠。新堆不生成散牌，卡牌正反面与正逆位状态保持不变。

专项回归：`python3 tests/run_pile_classify_tests.py`；同时通过牌堆抽取、类型初始化、生命周期、换卡组、名称编辑和音效回归。解析检查使用 Godot 4.7.2 `--headless --editor --quit` 与专项脚本 `--check-only`。
